بيانات اعتماد API

بيانات اعتماد API تتيح للتطبيقات الخارجية الوصول إلى واجهة برمجة تطبيقات معدوم بشكل آمن نيابةً عنك. أنشئ رمزًا (Token) لكل عملية ربط، وألغِه في أي وقت لا تحتاجه فيه.

اسم الرمز مفتاح API تاريخ الإنشاء آخر استخدام الحالة الإجراءات

لا توجد رموز API حتى الآن

أنشئ أول رمز لك للبدء في ربط تطبيقات خارجية بواجهة برمجة تطبيقات معدوم.

حافظ على أمان بيانات اعتمادك

  • لا تكشف API Secret أبدًا في تطبيقات الواجهة الأمامية (Frontend) أو في كود يعمل على المتصفح.
  • غيّر بيانات الاعتماد بشكل دوري، خصوصًا في بيئات الإنتاج (Production).
  • احذف بيانات الاعتماد غير المستخدمة بمجرد التوقف عن استخدام عملية الربط.
  • خزّن المفاتيح السرية في خزنة آمنة (Vault) أو متغيرات بيئة، ولا تحفظها كنص واضح أبدًا.

إنشاء رمز API جديد

اختر اسمًا للرمز حتى تتعرف عليه بسهولة لاحقًا.
