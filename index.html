توثيق API

نظرة عامة على API

نظام API متكامل يوفر إمكانيات شاملة لإدارة فرق العمل والتذاكر والويب هوك. يدعم النظام المصادقة عبر JWT أو مفاتيح API مع نظام صلاحيات متقدم.

Base URL: https://api.mad3oom.online/api/v1

الميزات الرئيسية:

  • إدارة فرق العمل والأعضاء والأدوار
  • نظام تذاكر متقدم مع الأولويات والحالات
  • الويب هوك مع التوقيع والتحقق من الأمان
  • سجلات API شاملة لكل عملية
  • مفاتيح API مع صلاحيات قابلة للتخصيص

المصادقة (Authentication)

يدعم النظام طريقتين للمصادقة: JWT Tokens و API Keys. اختر الطريقة المناسبة لحالتك.

1. JWT Authentication

HTTP Headers
Authorization: Bearer <JWT_TOKEN>
Content-Type: application/json

2. API Key Authentication

HTTP Headers
X-API-Key: mad_<random_string>
Content-Type: application/json

الصلاحية الوصف
read قراءة البيانات
create إنشاء بيانات جديدة

تحديث حالة التذكرة

الويب هوك (Webhooks)

الويب هوك تسمح لتطبيقك بتلقي إشعارات فورية عند حدوث أحداث مهمة. كل حدث يتم توقيعه بـ HMAC-SHA256 للتحقق من الأمان.

أنواع الأحداث:

  • ticket.created - عند إنشاء تذكرة جديدة
  • ticket.updated - عند تحديث التذكرة
  • ticket.deleted - عند حذف التذكرة
  • ticket.replied - عند إضافة رد على التذكرة
  • api_key.created - عند إنشاء مفتاح API
  • api_key.revoked - عند إلغاء مفتاح API

رؤوس الويب هوك:

HTTP Headers
X-Mad3oom-Event: ticket.created
X-Mad3oom-Timestamp: 1620000000
X-Mad3oom-Signature: sha256=<hmac_signature>

التحقق من التوقيع (Node.js):

JavaScript
const crypto = require('crypto');

function verifyWebhookSignature(payload, signature, secret) {
    const hash = crypto
        .createHmac('sha256', secret)
        .update(JSON.stringify(payload))
        .digest('hex');
    
    return hash === signature;
}

أمثلة برمجية

JavaScript - إنشاء تذكرة

JavaScript
const API_KEY = 'mad_your_api_key_here';
const BASE_URL = 'https://api.mad3oom.online/api/v1';

async function createTicket(subject, description, priority) {
    try {
        const response = await fetch(`${BASE_URL}/tickets`, {
            method: 'POST',
            headers: {
                'X-API-Key': API_KEY,
                'Content-Type': 'application/json'
            },
            body: JSON.stringify({
                subject,
                description,
                priority,
                created_by: 'user@example.com'
            })
        });

        if (!response.ok) {
            throw new Error(`API Error: ${response.status}`);
        }

        const data = await response.json();
        console.log('Ticket created:', data);
        return data;
    } catch (error) {
        console.error('Error:', error);
    }
}

// الاستخدام
createTicket('مشكلة في التطبيق', 'التطبيق لا يعمل', 'high');

Python - إنشاء تذكرة

Python
import requests
import json

API_KEY = 'mad_your_api_key_here'
BASE_URL = 'https://api.mad3oom.online/api/v1'

def create_ticket(subject, description, priority):
    headers = {
        'X-API-Key': API_KEY,
        'Content-Type': 'application/json'
    }
    
    payload = {
        'subject': subject,
        'description': description,
        'priority': priority,
        'created_by': 'user@example.com'
    }
    
    try:
        response = requests.post(
            f'{BASE_URL}/tickets',
            headers=headers,
            json=payload
        )
        
        if response.status_code == 201:
            data = response.json()
            print(f'Ticket created: {data}')
            return data
        else:
            print(f'Error: {response.status_code}')
            
    except requests.exceptions.RequestException as e:
        print(f'Request Error: {e}')

# الاستخدام
create_ticket('مشكلة في التطبيق', 'التطبيق لا يعمل', 'high')
